# 도식 아이콘 출처

기존 브랜드 로고는 루트의 `logos.js`를 재사용합니다. 아래 SVG는 공식 저장소·사이트에서 가져왔으며 원본 형태와 색상을 유지합니다. 상표 권리는 각 소유자에게 있습니다.

- [opentelemetry.svg](https://raw.githubusercontent.com/cncf/artwork/b4b5989332c822ef09d5b38a512e2b39c63e32f2/projects/opentelemetry/icon/color/opentelemetry-icon-color.svg)
- [gateway-api.svg](https://raw.githubusercontent.com/kubernetes-sigs/gateway-api/a35d46e1e302f9341d40e5a87343a7a83bb487b4/site/static/images/logo/logo.svg)
- [kiali.svg](https://raw.githubusercontent.com/kiali/kiali.io/be811a609c7fece3ca9957a0ef27791be5abbe63/assets/icons/logo.svg)
- [loki.svg](https://grafana.com/static/img/logos/logo-loki.svg)

추가 브랜드 로고는 기존 `logos.js`와 같은 Simple Icons 출처를 사용합니다. FastAPI는 `#009688`, Synology는 어두운 배경에서 식별할 수 있도록 중립색 `#d8dcdf`로 표시합니다. Synology는 원본 경로를 유지하고 viewBox의 상하 여백만 줄여 가로형 워드마크로 배치합니다.

- [fastapi.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/c71c69e3a27e4436936b831c72643e6513b9f49b/icons/fastapi.svg)
- [synology.svg](https://raw.githubusercontent.com/simple-icons/simple-icons/c71c69e3a27e4436936b831c72643e6513b9f49b/icons/synology.svg)

`gitops.svg`는 이 도식용으로 작성한 일반 기능 아이콘이며 제품 로고가 아닙니다.
