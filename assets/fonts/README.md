# 이력서 폰트

Pretendard 1.3.9의 Regular·Bold WOFF2 파일을 사용합니다.
PDF에 한글과 영문 글꼴을 포함해 텍스트 복사 시 글자 순서가 흩어지는 문제를 방지합니다.

- 공식 배포: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/web/static/woff2
- 라이선스: SIL Open Font License 1.1 (`Pretendard-LICENSE.txt`)

폰트는 원본 그대로 보관합니다. PDF 생성 시 `document.fonts.ready` 완료 후 출력합니다.
